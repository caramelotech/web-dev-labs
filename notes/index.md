# Web Dev Labs

Base de conhecimento sobre **desenvolvimento web** do Caramelo Tech - do HTML ao system design.

## O que você vai encontrar

- **Fundamentos Web** - HTML e CSS
- **Engenharia de Software** - design de código, princípios SOLID
- **APIs** - HTTP e REST
- **Databases** - SQL, ACID, CAP/PACELC e NoSQL
- **System Design** - fundamentos, capacity planning, latência e metodologia de projeto
- **Escalabilidade e Infraestrutura** - escala vertical/horizontal, CDN, load balancer, API Gateway, cache e rate limiting
- **Sistemas Distribuídos** - consistência forte vs eventual e replicação
- **Transações Distribuídas** - consistência entre microsserviços, Sagas, dual-write
- **Mensageria** - filas, Kafka e garantias de entrega
- **Microsserviços** - fundamentos e comunicação entre serviços
- **Resiliência** - timeout, retry, circuit breaker, idempotência e disponibilidade
- **Observabilidade** - logs, metrics e traces
- **System Design na Prática** - estudos de caso resolvidos (ex: encurtador de URL)
- **Ferramentas** - Git, Conventional Commits, Pull Requests, fluxos de trabalho e assinatura GPG

Navegue pelas seções na barra lateral. Se está começando, comece por Fundamentos Web.

As seções seguem uma progressão pensada para entrevistas de backend: da escrita de código (Engenharia de Software, APIs, Databases) até sistemas distribuídos em escala (System Design, Escalabilidade, Sistemas Distribuídos, Transações Distribuídas, Mensageria, Microsserviços, Resiliência e Observabilidade).
